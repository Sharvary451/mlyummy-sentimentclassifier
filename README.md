# MLYummy Sentiment Analysis 

Built a sentiment classification model for food review text. Deployed as a Streamlit app with real-time prediction capability.

## 🔧 Tools & Technologies
- Python, Scikit-learn, Streamlit, NLTK
- TF-IDF, Logistic Regression, Random Forest

## 💬 Methods
- Cleaned and vectorized review data
- Used ensemble models for better accuracy
- Achieved 94% F1-score

## 🧪 Results
- Instant predictions via browser app
- Simple UI built with Streamlit
